# QiwenOS

> 🚀 一个基于《操作系统真象还原》从零实现的教学型操作系统（面向底层研发能力提升）

---

## 📌 项目简介

QiwenOS 是一个参考《操作系统真象还原》完整实现的简易操作系统项目，涵盖了从 **引导加载 → 进入保护模式 → 内核初始化 → 进程调度 → 内存管理 → 文件系统** 的核心流程。

该项目使用 **C 语言 + x86 汇编语言** 开发，在 Bochs 模拟器上运行，强调对操作系统底层机制的“可实现理解”，而不仅是理论学习。

👉 本项目适合作为：
- 操作系统课程设计 / 实验项目
- 求职 **系统方向 / 后端研发 / 内核方向** 的项目经历
- 深入理解 OS 核心机制的实践项目

---

## 🧠 技术亮点（求职重点）

- ✅ 从 0 实现操作系统启动流程（MBR → Loader → Kernel）
- ✅ 熟悉 x86 架构与保护模式切换机制
- ✅ 掌握中断机制（IDT / PIC / 中断处理流程）
- ✅ 实现内核级线程与调度（时间片轮转）
- ✅ 实现分页机制（虚拟内存管理）
- ✅ 实现简易文件系统（inode + 数据块）
- ✅ 掌握用户态 / 内核态切换与系统调用机制
- ✅ 熟悉底层调试工具（Bochs）

---

## 🚀 已实现功能

### 🧱 引导与系统启动

- 自定义 **MBR（主引导记录）**
- Loader（二级引导程序）加载内核
- 从磁盘读取内核到内存指定位置
- 完成实模式 → 保护模式切换

---

### ⚙️ 内核核心机制

- 32 位保护模式运行环境搭建
- GDT（全局描述符表）构建
- IDT（中断描述符表）初始化
- 完整中断处理机制（含硬件中断）

---

### 🧵 线程与调度

- 内核级线程创建与管理
- PCB（进程控制块）设计
- 基于时间片轮转的调度算法
- 线程上下文切换实现（寄存器保存/恢复）

---

### 🧠 内存管理

- 物理内存位图管理
- 虚拟内存分页机制（页表构建）
- 地址映射（虚拟地址 → 物理地址）
- 内核空间与用户空间划分

---

### 📁 文件系统

- 简易类 Unix 文件系统设计
- 支持文件创建、读取、写入、删除
- 目录结构管理
- inode + 数据块管理机制

---

### ⌨️ 设备管理与 IO

- 键盘驱动（中断驱动方式）
- 显存操作实现字符输出
- 基础输出接口（put_char 等）

---

### 🔧 系统调用机制

- 用户态与内核态切换
- 系统调用入口设计
- 提供基础内核服务接口

---

## ⚠️ 环境要求

为保证项目正常编译与运行，需要严格满足以下环境：

### 🖥️ 系统环境

- Linux（推荐 Ubuntu）
- x86_64 架构

---

### 🧰 编译工具

- **GCC = 4.4（强制要求）**
  - 高版本 GCC（如 5.x / 7.x / 13.x）可能导致：
    - 编译失败
    - 内联汇编不兼容
    - 内核行为异常

---

### 📦 依赖工具

- `nasm` —— 汇编编译器  
- `make` —— 构建工具  
- `bochs` —— x86 模拟器（用于运行系统）

## ⚙️ 使用说明

### 1️⃣ 修改磁盘镜像路径

编辑 `Makefile`：

makefile path = /your/path/to/hd60M.img

将其修改为你本地 hd60M.img 的实际路径。

---

2️⃣ 编译并运行

在项目根目录执行：

make all

该命令将自动完成：

编译引导程序（MBR + Loader）

编译内核

写入磁盘镜像

启动 Bochs 模拟器运行系统



---

🖥️ 运行效果

成功运行后，你将看到：

系统完成从 BIOS → MBR → Loader → Kernel 的完整启动流程

进入自定义内核环境

屏幕输出初始化信息

键盘输入可被正确响应

多线程调度正常运行

文件系统可进行基础操作（如创建/读写文件）



---

❗ 常见问题

1. 编译报错 / 无法通过

请确认 GCC 版本为 4.4

使用 gcc -v 检查版本

高版本 GCC 不兼容本项目



---

2. Bochs 无法启动 / 黑屏

检查 hd60M.img 路径是否正确

确保 Bochs 配置文件无误

确认镜像已成功写入（make 过程无报错）



---

3. 运行异常 / 输出不正确

检查是否在正确的 x86 环境下运行

确保未修改关键内核代码逻辑

建议使用 Bochs 调试模式逐步排查



---

4. make 无法执行

检查是否安装 make

检查 Makefile 是否被误修改
