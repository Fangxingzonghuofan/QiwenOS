# QiwenOS

> 一个基于《操作系统真象还原》从零实现的教学型操作系统，旨在深入理解操作系统核心机制与底层实现原理。

## 快速启动

配置好bochs后在项目根目录执行如下命令：

```bash
make all
```

或者手动编译运行：

```bash
make mk_dir boot build hd
```

## 内存管理

- **位图(bitmap)管理物理内存**：使用位图作为物理内存块的分配与释放管理机制
- **虚拟内存分页机制**：实现完整的虚拟内存到物理内存的映射，包含页目录和页表管理
- **内核空间与用户空间分离**：在虚拟内存层面将用户空间与内核空间分隔开，提供内存隔离
- **内存池管理**：使用物理内存池与虚拟内存池分别管理物理内存与虚拟内存资源
- **多级内存块管理**：针对不同大小的内存块(16、32、64、128、256、512、1024字节)提供高效的分配回收

## 进程管理

- **线程实现**：基于PCB(Process Control Block)结构体记录线程信息
- **时间片轮转调度**：采用FIFO轮询调度方式，实现基本的时间片分配机制
- **上下文切换**：通过汇编代码实现完整的线程上下文切换，包括寄存器保存与恢复
- **内核线程管理**：实现内核级线程的创建、调度、阻塞、销毁等基本操作
- **TSS机制**：利用x86架构的TSS(Task State Segment)结构支持线程切换

## 系统调用与特权级转换

- **中断门实现系统调用**：效仿Linux使用0x80号中断作为系统调用入口
- **特权级转换机制**：在TSS段等硬件支持与软件抽象层上，实现用户进程与内核之间的特权级转换
- **系统调用表**：建立系统调用子功能表，利用eax寄存器中的子功能号索引相应的处理函数
- **用户空间接口**：用宏实现用户空间系统调用接口，最大支持3个参数的系统调用，通过寄存器传参

## 同步与竞争

- **信号量机制**：实现基于计数器的信号量，解决多个线程间的同步问题
- **互斥锁**：实现基本的互斥锁，解决临界资源的竞争问题
- **原子操作**：提供基础的原子操作支持，确保共享数据的安全访问

## 文件系统

QiwenOS中实现了基于ext2文件系统的简化版文件系统。

- **inode结构管理**：使用inode结构体管理文件的元数据和数据块索引
- **超级块管理**：Super block负责保存文件系统元信息：inode数组的地址及大小、inode位图地址及大小、根目录的地址和大小、空闲块位图的地址及大小
- **目录管理**：支持目录结构管理，包括多级目录的创建、遍历和删除
- **文件操作**：支持文件创建、读取、写入、删除等基本操作
- **块管理**：使用数据块管理文件的实际内容，实现文件存储与检索

## 设备驱动

- **键盘驱动程序**：实现完整的键盘驱动程序，支持按键扫描码解析与字符输入
- **IDE硬盘驱动程序**：实现ATA磁盘设备的驱动程序，支持扇区级读写操作
- **中断驱动通信**：通过中断的方式完成与CPU的异步通信
- **I/O队列**：使用缓冲队列管理设备I/O操作，提高系统响应效率

## 交互式终端

- **简易Shell实现**：实现基本的命令行解释器
- **常用命令支持**：支持cd、ls、ps、pwd、mkdir、touch、rm等常用命令
- **系统调用接口**：提供统一的系统调用接口给用户程序使用

## 核心架构特性

- **32位保护模式**：从实模式切换到保护模式，建立完整的GDT、IDT
- **中断处理机制**：完整的中断描述符表(IDT)和中断处理框架，支持硬件中断和软件中断
- **引导流程**：从MBR到Loader再到Kernel的完整引导过程
- **汇编与C混合编程**：熟练使用x86汇编与C语言进行底层系统编程
- **内存保护**：通过段页式内存管理提供内存保护机制

## 技术栈

- **编程语言**：C语言 + x86汇编语言
- **开发平台**：Bochs x86模拟器
- **架构支持**：x86 32位架构
- **编译环境**：GCC 4.4 (严格要求版本)
